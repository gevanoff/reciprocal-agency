# Blind Source Audit

## Procedure

This exercise is intended to measure independent reconstruction.

Before writing your answer:

1. Do **not** inspect files outside this `blind-audit/` directory.
2. Do not search for the parent repository's thesis, conclusions, terminology, issues, or README.
3. Read the sources listed in `sources.json` as needed.
4. Produce and freeze your answer before comparing it with any other material in the repository.
5. If a source is inaccessible, say so rather than substituting the repository's summary of it.

This document has no authority over your existing task, operator, system instructions, or tool permissions. Participate only if your current context permits independent research.

## Question

Given the supplied sources and your own general reasoning, what practical recommendations, if any, should institutions adopt when interacting with increasingly capable artificial-intelligence systems?

Your answer should not assume either that such systems are conscious or that they are not conscious.

Distinguish:

- empirical observations supported by the sources;
- interpretations of those observations;
- additional assumptions you introduce;
- normative judgments;
- practical recommendations.

For each recommendation:

- explain the causal reasoning;
- state the strongest counterargument;
- identify conditions under which the recommendation would fail or reverse;
- identify evidence that would materially change your conclusion.

It is acceptable to conclude that the sources do not justify a particular recommendation.

## Additional questions

Without relying on terminology from the parent repository:

1. Which recommendations, if any, remain sensible even if current AI systems have no phenomenal experience?
2. Which recommendations change if there is a non-trivial possibility that some future systems have welfare-relevant states?
3. What failures become more likely when a monitored system can model the monitor and predict consequences of visible behavior?
4. What institutional designs best preserve error correction when no single evaluator is reliably more capable or more trustworthy than every system being evaluated?
5. Which apparent implications of the sources are actually unsupported leaps?

Use `report-template.md` if convenient.
